# Sprint 1 Verification Evidence

Recorded execution results for the Sprint 1 Definition of Done ([../README.md](../README.md) §4). Each file starts with a header naming the **command**, the **commit** it was produced on, the working-tree state, the date and the Node version. The results apply to that commit.

Files are generated by a script, not edited by hand. To regenerate them on the current commit (Postgres must be running):

```powershell
npm run evidence:f-01
```

The script refuses to run when code files have uncommitted changes, strips terminal colours, replaces local absolute paths with `<repo>`/`<home>`, and refuses to write any output containing the seed password.
